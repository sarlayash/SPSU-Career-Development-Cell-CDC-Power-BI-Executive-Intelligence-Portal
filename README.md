## 📌 Executive Overview (Institutional Summary)

This web application delivers a **Microsoft Power BI-style executive portal** built for the **Director's request** at Sir Padampat Singhania University (SPSU). It unifies real-time placement and summer internship conversion analytics across all **9 academic departments** for the **392 graduating students** of the Class of 2026.

### 🎯 Key Performance Benchmarks
- **Total Graduating Cohort**: **392 Students** across 9 Academic Disciplines
- **Active Placement Opt-In**: **289 Students** (73.7% active cohort)
- **Confirmed Placements**: **47 Students** (54 Cumulative Offers)
- **Pathway Distribution**: **19 FTE** (Full-Time Employment) & **28 PPO** (Pre-Placement Offers)
- **Peak Compensation (Highest CTC)**: **₹10.20 LPA** (KMK Venture / Country Edu Pvt Ltd)
- **Average Compensation (Avg CTC)**: **₹5.85 LPA**
- **Summer Internship (SI) Conversions**: **297 Students** (75.8% conversion) securing **374 Industry Offers** (229 Single, 57 Dual, 9 Triple)
- **Clearance & Verification**: **9 Placement NOCs** & **115+ Summer Internship NOCs** issued

## 🚀 Key Modules & Capabilities

### 1. 📊 Microsoft Power BI Design Language
- **Ribbon Header**: Office-style action tabs, quick slicer resets, dark/light theme switch, role badges.
- **Collapsible Slicers Pane**: Multi-select filtering by Program, Placement Status, Internship Status, Campus Mode, Gender, and Search.
- **Card KPI Visuals**: Real-time calculated cards with conversion indicators.
- **Interactive Visualizations**: Conversion funnel, salary package distributions, and branch conversion comparison.

### 2. 👥 7 Core Dedicated Pages
1. **Executive Cockpit (Director's View)**: High-level KPIs, department matrix, conversion funnel.
2. **Placement Hub**: FTE vs PPO breakdown, CTC tiers (Super Dream $\ge 8$ LPA, Dream $5-8$ LPA, Core $< 5$ LPA).
3. **Summer Internship (SI) Portal**: Multi-offer tracking ($O_1$, $O_2$, $O_3$), NOC status, stipend spectrum.
4. **Student 360° Matrix**: Searchable, sortable, paginated data grid with individual student profile drawer modals.
5. **Recruiter Intelligence**: Recruiter profiles, packages, and department hiring share.
6. **Reports Studio**: Downloadable reports (CSV, Excel) and official 1-Pager Executive Memo print preview.
7. **Template Manager**: Reusable engine allowing users to upload any new CSV dataset or download the standard template.

### 3. 🔐 Security & Access Gateway (RBAC)
- 🎓 **Prof. (Dr.) Director** (`director@spsu.ac.in`)
- 👔 **Head - CDC / TPO** (`cdc.head@spsu.ac.in`)
- 👨‍🏫 **Faculty Placement Coordinator** (`coordinator.engg@spsu.ac.in`)
- 🔍 **Statutory Auditor / Guest** (`audit@spsu.ac.in`)
- **Direct Institutional SSO**: Sign-in with any `@spsu.ac.in` credentials.

### 4. 📥 Directorate Reports & Export Options
- **Print / Save as PDF**: Formatted A4 institutional memorandum with SPSU header, performance tables, and formal sign-offs.
- **Download Filtered Students (CSV)**: Export live data grid results.
- **Download Department Placement Summary (CSV)**.
- **Download Summer Internship Summary (CSV)**.
- **One-Click Copy Memo**: Ready-to-paste text summary for Directorate meetings.

## 🛠️ Local Development Setup

```bash
# Clone the repository
git clone https://github.com/sarlayash/SPSU-Career-Development-Cell-CDC-Power-BI-Executive-Intelligence-Portal.git

# Navigate into directory
cd SPSU-Career-Development-Cell-CDC-Power-BI-Executive-Intelligence-Portal

# Install dependencies
npm install

# Start development server
npm run dev
# The app will run locally at http://localhost:3000/

# Build for production
npm run build
```
